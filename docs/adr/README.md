# Architecture Decision Records

Use the `NNNN-short-title.md` convention. Each ADR records context, decision, alternatives, consequences, date, status, and related requirements/tickets.

An accepted ADR is immutable except for factual corrections; supersede it with a new ADR that references the old one. Proposed ADRs may be refined until the blocking decision is approved.
