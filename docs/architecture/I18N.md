# French baseline and Arabic-ready architecture

- Launch locale: `fr_FR`.
- The locale remains a WordPress site setting; custom code does not override administrator or customer locale selection.
- Business timezone: `Africa/Tunis`.
- Core plugin text domain: `jouvence-para-core`.
- Theme text domain: `jouvence-para`.
- Taxonomy/attribute IDs and slugs are stable machine identifiers.
- No Arabic content is shipped by JP-I18N-001.
- No alternate hreflang is emitted until a translated page really exists.
- Future RTL work must use WordPress locale/direction APIs and logical CSS, not a forked theme.
